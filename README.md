# NVIDIA NIM NPC Chat

Talk to ordinary Pokémon Blue NPCs by typing your own question and receive a
short, in-character answer generated by an NVIDIA NIM LLM.

The mod is installed in `mods/nim_npc_chat` and newly installed mods are
enabled by default. It reads the API key only from the process environment;
the key is never written into the mod, save game, logs, or curl command line.
For curl, it uses a private short-lived header file that is deleted after the
request; an interrupted request is cleaned automatically on the next launch.

## Run it on Windows

The mod reads the same `NVIDIA_API_KEY` process environment variable as the
Real-time Auto Subtitles code on this machine. From PowerShell in the
`gen1recomp` directory:

```powershell
$env:NVIDIA_API_KEY = "nvapi-your-key"
.\Play-Windows.bat
```

Walk up to an ordinary NPC and press A. Type with a keyboard and press Enter,
or use the on-screen letter grid with a controller (A selects, B deletes,
START sends). Escape or EXIT cancels.

The default hosted endpoint is
`https://integrate.api.nvidia.com/v1/chat/completions`, using
`minimaxai/minimax-m3`. Both earlier defaults are unusable:
`meta/llama-3.1-8b-instruct` reached end of life on the hosted NIM API and
answers `410 Gone`, while `mistralai/mistral-7b-instruct-v0.3` is still
listed by `/v1/models` but answers `404 Function ... Not found for account`
because its backing function is gone. Override either value before launch
when needed:

```powershell
$env:NVIDIA_NIM_MODEL = "another/model-id"
$env:NVIDIA_NIM_BASE_URL = "https://integrate.api.nvidia.com/v1"
```

`NVIDIA_NIM_BASE_URL` may also point to a self-hosted NIM base URL. The mod
appends `/chat/completions` unless that suffix is already present.

## Safety and game progression

Only `dialogue` NPCs are replaced. Story scripts, item balls, static Pokémon,
unbeaten trainers, marts, nurses, PCs, and Cable Club receptionists retain
their original handlers so an LLM cannot block progression or fabricate a
game-state change. Defeated trainers and ambient residents can chat. Original
runtime dialogue is supplied as persona context, and up to three recent turns
are remembered in memory until the game closes.

The service receives the player's typed message, map identifier, and that
NPC's original line. Do not type sensitive information. Generated replies can
be wrong or out of character.

Desktop curl is required. Android/iOS currently expose only a download bridge
in this port, so JSON POST is intentionally reported as unsupported there.

## Verify

```powershell
python tools/modkit.py validate mods/nim_npc_chat --base imported
luajit mods/nim_npc_chat/tests/nim_npc_chat_test.lua
```

If only the bundled Windows LÖVE runtime is installed, use its LuaJIT through
the included wrapper:

```powershell
$env:MODKIT_LUAJIT = (Resolve-Path tools/love-luajit.cmd)
python tools/modkit.py validate mods/nim_npc_chat --base imported
```
